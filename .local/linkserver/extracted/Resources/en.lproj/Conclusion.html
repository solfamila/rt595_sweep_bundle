To use LinkServer, open a Terminal window at

/Applications/LinkServer_25.12.83

 

To access the inline help:

% ./LinkServer [COMMAND] -h

 

To list and boot connected probes:

% ./LinkServer probes

 

To list all the supported devices:

% ./LinkServer devices

 

To list devices matching a given substring:

% ./LinkServer devices -f RT10

 

To start GDB server for a particular device:

Debug mode (select by device name):

% ./LinkServer gdbserver k28

Attach mode (select by board name):

% ./LinkServer gdbserver :LPCXpresso54114 -a

Multicore (select by device & board name):

% ./LinkServer gdbserver MIMXRT1176xxxxx:MIMXRT1170-EVK -c all

 

To execute flash operations using the graphical user interface:

% ./LinkFlash
